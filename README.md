# HookWood Tuition Center

A modern education management system for HookWood Tuition Center in Nairobi, Kenya.

## Features
- Responsive website
- Cambridge, CBC & KCSE programs
- Online admissions
- Student dashboard
- Teacher dashboard
- Admin dashboard
- Results management
- Attendance tracking
- Fee management

## Technologies
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- Bootstrap 5
